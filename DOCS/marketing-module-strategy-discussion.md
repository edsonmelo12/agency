# Estratégia de Criativos + Texto por Etapa do Funil  
Objetivo: alinhar o módulo de marketing com o comportamento de um gestor de tráfego experiente antes de implementar novas gerações automáticas.

## 1. Variantes por etapa
- **Topo (Awareness):**
  - Opções: (a) vídeo curto + storytelling (dor → solução); (b) carrossel “antes/depois”; (c) creative quiz/pergunta que desperta curiosidade.
  - Pergunta-chave: qual estilo gera mais retenção e engajamento nos anúncios iniciais?
- **Meio (Consideração):**
  - Opções: (a) autoridade (depoimento, números, provas); (b) comparativo (nosso diferencial vs. alternativas); (c) tutorial soft-selling.
  - Pergunta-chave: que texto ajuda o público a confiar sem parecer “mais do mesmo”?
- **Fundo (Conversão):**
  - Opções: (a) prova social + CTA direto; (b) urgência/escassez; (c) remarketing com depoimento pessoal + garantia.
  - Pergunta-chave: qual variação reduz a hesitação final e mantém a promessa da oferta?

## 2. Quantidade/qualidade do texto
- Definir guidelines e alertas no painel:
  - Headline ≤ 14 palavras.
  - Corpo ≤ 90 palavras.
  - CTA ≤ 5 palavras.
  - Vídeo ≤ 30 segundos com 3 frases principais.
- Discussão: qual limite o time acredita que preserva clareza sem castrar a narrativa?
- Monitoramento: registrar CTR e taxas de regeneração para variações que ultrapassam os limites.

## 3. Tags e aprendizado contínuo
- Marcar cada criativo gerado com tags (emocional, autoridade, direto, urgência).
- Usar as tags para sugerir automaticamente qual variação deve ir para cada conjunto (broad/lookalike/remx) e para indicar o estilo vencedor.
- Pergunta-chave: quando um criativo deve ser regenerado com outro eixo (ex: de emocional para factual)?

## 4. Documentação e próximos passos
- Coletar respostas e decisões em um quadro (issue/kanban).
- Atualizar prompts/componetes com os limites e alertas definidos.
- Planejar testes de performance (CTR, ROAS, tempo de aprovação) para as novas variações.
