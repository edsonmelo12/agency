# Task List por Skill — Módulo de Marketing

Este check-list transforma os próximos passos em tarefas acionáveis, apontando qual skill lidera cada entrega.

| Skill | Tarefa | Responsável sugerido | Critério de aceite |
| --- | --- | --- | --- |
| **copywriting** | Documentar prompts do Planner, Criativos e Builder com exemplos de input/output, definindo mensagens de erro/fallback exibidas no novo painel. | Redator/IA | JSON padronizado, voz da marca definida, termos proibidos evitados e mensagens claras. |
